# Worker Pool - K8S Powered Storage API

K8S-powered Storage API с реализацией паттерна Worker Pool для высокопроизводительной обработки HTTP-запросов к PostgreSQL. Приложение автоматически масштабируется в Kubernetes, обеспечивает контроль нагрузки через ограниченную очередь задач и параллельную обработку запросов несколькими воркерами, что предотвращает перегрузку сервера и гарантирует стабильную производительность даже при пиковых нагрузках. Готовая инфраструктура включает деплой PostgreSQL с persistent storage, мониторинг через Prometheus с метриками RPS и latency, и полную конфигурацию для production-ready окружения.
